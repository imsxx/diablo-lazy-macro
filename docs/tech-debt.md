## 二、需要实机确认的现象

1. **125% / 150% 显示缩放**：窗口已按 DPI 等比放大、CSS 视口恒为基准尺寸（`window.go` 的 `scaledSize`），算术上不裁切，但未在缩放机器上实测。
2. **冷启动白屏**：CBT 钩子把窗口建在屏幕外，等 `api_ready` 或 600ms 兜底再显示；WebView2 冷启动偏慢时仍可能有短暂空窗，需在慢机器上观察。
3. **弹窗期间/之后**：原生 `MsgBox` 打开时，托盘与悬浮窗触发的"显示主窗口"是否正常（与上表"双 GUI 工具集"同一推断）。
