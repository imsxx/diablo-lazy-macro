# Diablo Lazy Macro · 暗黑懒人宏

> 腱鞘炎一生之敌。*The lifelong enemy of your wrists.*

暗黑破坏神系列**专用**键鼠宏工具：一个程序覆盖**暗黑破坏神4 / 暗黑破坏神3**，不必为每一代游戏分别找工具、分别配一遍。支持连点、按住不放、单点、定时刷新，以及由屏幕取色驱动的 Buff 保持。**不内置方案预设**——每套 BD 用哪些技能、技能摆在哪几个键位都不确定，预设只会逼玩家先删掉用不上的配置；配置靠作者在工具内调好后导出「分享码」，玩家粘贴导入即完成。

## 底线与功能分层

### 唯一底线：不做无人值守

**不做挂机与全自动打怪**：所有功能都必须有人在场——按键触发、手动开启、随时可停。这条底线不绕过、不例外。

### 为什么只有这一条

暗黑破坏神3 自发行以来，暴雪对按键宏长期保持宽容：封禁案例集中在无人值守的全自动挂机，按键宏（与雷蛇/罗技驱动宏属同一技术类别）并未因此被禁。而**暗黑破坏神4 缺少公开的长期验证**，因此对暗黑4采取保守策略，功能按风险分层投放。

### 功能风险分层

| 等级 | 功能 | 投放策略 |
| --- | --- | --- |
| 绿 | 连点 / 按住不放 / 单点、Buff 保持、方案切换、快速暂停 | 两款游戏均可用 |
| 黄 | 自动分解 / 重铸 / 升级 / 转换 / 拾取 / 赌博、按键队列、智能暂停 | 暗黑3 先行；**默认关闭**，界面明确标注未在其他游戏验证、风险自负 |
| 红 | 无人值守挂机、全自动打怪巡航 | 不做，也不接受相关贡献 |

### 技术手段约束（不随功能放宽而放宽）

- **不读游戏内存、不注入进程、不加载驱动**：只合成键鼠输入，屏幕识别仅使用公开的截图与取色
- **仅在目标游戏位于前台时发送**：切出游戏立即停止
- **Go 原生实现，不依赖 AHK 等脚本运行时**：与暴力外挂生态保持距离，同时换取干净的杀软表现与可维护性

## 助手功能（暗黑3 · 黄区）

在铁匠铺、卡奈魔盒、商人等处一键完成重复操作。**默认全部关闭**，需在主窗口右栏「辅助功能」卡片里勾选启用（该卡片只在选中暗黑3 时出现）。

| 助手 | 前置条件 | 说明 |
| --- | --- | --- |
| 快速分解 | 铁匠铺的分解页，且鼠标指向背包里的装备 | 点一次左键，弹出确认框时自动回车确认 |
| 卡奈魔盒 · 重铸 | 魔盒的重铸页，且鼠标指向要重铸的装备 | 可设定目标品质，达到即停；上限 30 次 |
| 卡奈魔盒 · 升级/转化 | 魔盒的升级页或材料转化页 | 逐个把背包装备送进魔盒执行一次 |
| 赌博 | 与商人对话打开的赌博界面 | 连按右键（默认 15 次） |
| 一键拾取 | 无 | 鼠标停在人物周围时连点左键（默认 20 次），否则只点一次 |

**三个使用前提**（任一不满足只会记录日志、不会乱点）：

1. 游戏以**窗口化 / 无边框窗口化**运行——全屏独占模式下无法屏幕取色；
2. 游戏位于**前台**——合成的键鼠输入只能发给前台窗口；
3. **技能宏处于停止状态**——助手与技能宏互斥（与 D3keyHelper 一致）。

按一次助手快捷键触发；**运行中再按一次即可打断**。全程会挪动光标，结束时自动还原到原位。

**开发者模式**：在同一设置面板里开启后，日志会记录每一步的取色值、判定结果与鼠标去向。遇到问题时把日志整段回传即可定位——**首次使用建议就打开**。

> 为什么归入黄区：这些功能是「识别界面并代替点击」，目前只在暗黑3 上验证过，且更依赖游戏版本与分辨率。因此默认关闭、按需开启、风险自负。

## 使用

1. 双击桌面快捷方式「暗黑懒人宏」（或运行 `dist\diablolazymacro.exe`）：**主窗口打开，同时托盘常驻**。标题栏右侧：`—` **最小化到托盘**（窗口收起、宏继续运行，双击托盘图标恢复）；`✕`（或 Alt+F4）**退出程序**，会先弹一个二次确认，确认后宏停止、托盘图标消失。托盘右键只有「打开界面 / 退出」两项，**其余操作都在主界面里完成**
2. 主窗口是**左右双栏仪表盘**（界面由内置 WebView2 渲染，需要系统已安装 Edge WebView2 运行时——Win10 1607+ / Win11 通常自带）：
   - **自上而下的语义分区**：标题栏（品牌、战斗宏启停键、**悬浮窗开关**、导入分享码 / 复制分享码 / 运行日志、窗口控制）→ **全局设置通栏**（启动方式、智能暂停、提示音、左键自动站立、快速暂停、悬浮窗显示方式——这些与游戏、与方案都无关）→ **游戏切换条**（暗黑4 / 暗黑3）→ 该游戏的配置区（左栏按键 / 右栏额外功能）→ 底部状态栏。**首次启动默认暗黑4**，之后记住你上次选的游戏（切到暗黑3，下次启动还是暗黑3）。启停键默认是**鼠标侧键·后退（X1）**——两款暗黑游戏的默认键位都不占用鼠标额外按键（而暗黑3 的 `F1` 是「收藏」、`Shift` 是「强制站立」，都不能用）
   - **左栏（方案）**：默认只有 **1 个方案**，标签上显示的就是你起的配置名；点标签尾部的 **「+」** 新增方案（协议上限 4 个，达到后加号置灰），新增后自动切过去、槽位全部为「禁用」，等你填。配置名右边的 **「删除」** 可删掉当前方案，会先弹一个说明后果的确认框（只剩 1 个时按钮置灰——至少保留 1 个）。每页编辑配置名、切换键、按键模式与 6 个技能槽位（技能一~四 + 左键技能 + 右键技能）。每个槽位一行放下全部参数：**释放策略**（禁用 / 按住不放 / 连点 / 保持Buff）、**执行间隔**、**延迟区间**（仅连点：两个框分别是最小/最大延迟，只填一个时另一个在失焦/回车后自动补成相同值＝固定延迟；两个不同就在区间内随机；都空＝不延迟）。工具**不设「数值太小视为关闭」的门槛**，间隔下限 1ms，填 2ms 就是 2ms，实际精度由系统与游戏决定。与当前策略无关的列会**淡化显示但不再锁死**——可以先填数值，把策略改成「连点」后立即生效（悬浮提示会说明当前为什么不生效）。**任何改动即时生效并写盘**，底栏会闪一下「改动即时生效」
   - **键位录入**：任何键位按钮点一下，会弹出录入浮层——按键盘上任意键即可（Esc 取消），也可以在浮层里直接点鼠标左/右/中键与侧键。键盘键的**合法性由工具判定**：不可用于当前键位的组合（例如把鼠标键绑成「方案切换键」）会当场提示原因，不会被写进配置
   - **方案切换**：每个方案可指定一个切换键（仅键盘键，可清除），游戏中按一下即切到该方案，不必回桌面开窗口
   - **按键模式**（每方案可独立选）：**并发按键**（默认）各技能各自计时、到点就按，互不影响；**循环按键**按槽位顺序一轮一轮按，一轮走完从头再来，与罗技/雷蛇驱动宏的顺序宏心智一致
   - **右栏（额外功能）**：目前只有**辅助功能**（暗黑3 专属：助手快捷键、动作速度、魔盒重铸目标、开发者日志与 5 个助手开关）；非暗黑3 时显示一张说明卡。左键自动站立只在暗黑3 生效：开启后工具会在连点左键技能前自动按住**强制站立键**，避免角色走动；键位默认 `LShift`（暗黑3 的默认绑定），可改成你自己的游戏键位
3. **在场游戏悬浮指示器（Mini HUD）**：默认开启，显示宏状态（就绪 / 运行中 / 已暂停 / 休眠）与「D3 · 配置名」。**开关在标题栏「悬浮窗」按钮**（全局，与游戏和方案无关）；可拖拽记忆位置、双击呼出主窗口、右键切换形态（战术横条 / 紧凑方标）、锁定位置与「仅前台显示」；形态等细项在同一行右侧，位置移出屏幕时可点「重置位置」
4. **宏启动方式**（顶部全局设置区）决定触发语义：
   - **懒人模式**：按一下启动快捷键开，再按一下关
   - **仅按下时**：按住启动快捷键（推荐用鼠标侧键）时才生效，松开立即停止
   - 无论哪种方式，**只有目标游戏位于前台时才会发送按键**；底栏的宏状态标签与悬浮指示器会同步显示「就绪 / 运行中 / 已暂停 / 休眠」
5. **导入分享码**：复制一段分享码 → 顶栏「导入分享码」→ 在浮层里核对预览（会列出声明的方案、规则与冲突提醒）→ 确认导入
6. 作者侧：点顶栏「复制分享码」即可把配置发给别人
7. 配置与日志在 `%APPDATA%\diablo-lazy-macro\`（顶栏「运行日志」窗口里有「打开数据目录」）

## 键位与游戏默认值的对应

工具的默认键位刻意避开游戏本身的功能键：

| 工具的键 | 默认值 | 说明 |
| --- | --- | --- |
| 启动快捷键 | **鼠标侧键·后退（X1）** | 两款暗黑游戏的默认键位都不占用鼠标额外按键；暗黑3 的 `F1` 是「收藏」、`Shift` 是「强制站立」，都不能用 |
| 强制站立键 | `LShift` | 与暗黑3 游戏内默认绑定一致；玩家改过键位就改成自己的 |
| 方案切换键 | 无（不设） | 需要时自己指定 |

以上全部可在工具内改：点键位按钮弹出录入浮层，按任意键盘键、或用浮层里的鼠标键按钮即录；方案切换键与强制站立键还能在浮层里一键清除 / 恢复默认（切换键按协议只接受键盘键）。

## 日志与问题反馈

- 顶栏 →「运行日志」：在界面内弹出日志浮层（与主界面同一套样式），可**复制全部**日志（含版本、系统、游戏与配置加载记录），直接贴给我们即可定位问题；也可在这里刷新、清空、打开数据目录
- 日志同时落盘：`%APPDATA%\diablo-lazy-macro\logs\app.log`（超过 2MB 自动轮转）

## Phase 0 验证结果（2026-10-10）

在真实游戏（暗黑4）内全项通过：

- **键盘合成输入被游戏接受**：按住触发键与 F1 持续模式下，技能正常连发
- **鼠标合成输入被游戏接受**：`-spam "RMB"` 右键技能连点在游戏内生效
- **触发键轮询有效**：鼠标侧键、鼠标左右键、数字键均可作为按住触发（零全局钩子）
- **前台保护有效**：仅当目标进程位于前台时才发送（进程名匹配）
- **权限**：游戏进程非管理员，普通权限运行即可，不存在 UIPI 拦截

## 分享码

分享码在**工具内**生成与消费：作者导出即复制，玩家从剪贴板粘贴导入。格式为 `DLM5:` 前缀 + base64url 编码的紧凑 JSON（可带游戏标识）；导入时工具会渲染一份人类可读摘要供核对，绝不执行码中的任何代码。协议见 [docs/share-code.md](docs/share-code.md)。

## 开发

```powershell
.\build.cmd          # 双击可用：构建 dist\diablolazymacro.exe（发布版，无控制台）
go run .             # 开发运行（带控制台，便于看日志）
go run ./cmd/probe   # 运行 Phase 0 输入探针（回归验证用）
go test ./...        # 单元测试（协议、引擎、存档、日志、界面槽位与键名映射）
go vet ./...         # 静态检查
```

> 界面改动（`web/` 三件套）也要跑一次 `go run .` 实机确认：单元测试覆盖不到渲染与交互。
> 界面接口约定：前端只渲染 Go 下发的状态，写操作「先校验后提交、失败回滚并把错误显示在提示条里」，
> 任何新增接口都要遵守这条，避免出现「界面改了、磁盘没写」的静默失败。

Windows 资源（应用图标 + Common Controls v6 清单 + 版本信息）由 `winres.json` 生成，产物已入库；改动后重新生成：

```powershell
go run ./tools/mkico -in 源图.png -out assets/icon.ico -png assets/icon.png   # 图标：去水印、圆角透明、多尺寸 ICO
go run github.com/tc-hib/go-winres@latest make --in winres.json --out rsrc --arch amd64,arm64
```

探针用法与游戏内测试清单见 [docs/probe-checklist.md](docs/probe-checklist.md)。
